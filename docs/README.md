# Docs

Everything written-down lives here. `CLAUDE.md` at the repo root stays put — it's the agent contract, not a doc.

- `demo-context/` — raw demo source material (merchant flows, question reviews, DS handbooks). Never modified; the wiki is compiled from it.
- `plans/` — implementation plans and roadmaps, one file per effort.
- `specs/` — design docs describing how a system works.
